# 1.Sum of Even numbers

A Python program that calculates the sum of all even numbers up to a user-provided integer and counts the number of even values using a while loop.
Example: For an input of 10, the sum is 30 and the count of even numbers is 5.

# 2. Stone, Paper, Scissors

A Python-based interactive game where the player competes against the computer through randomly generated choices. Uses conditional statements to determine the winner, validates user input, and implements a while loop to enable repeated rounds of gameplay with an option to replay. This challenge focuses on strengthening logical thinking, control flow, and fundamental Python programming skills.
